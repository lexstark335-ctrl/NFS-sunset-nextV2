# GAME OVER 车库遮挡修复

2026-11-05。按用户缩小后的范围，仅修改车库遮挡；BOOST 和音频模块保持原样。

原因：原 ROKU HUD 的 z-index 为 2600，整合车库为 2500，结束界面因而显示在车库上方。

- 将车库层级调整为 2800。
- 车库打开时添加 `racer-garage-open` 状态，立即隐藏原结束遮罩。
- 关闭车库移除此状态，恢复原 GAME OVER / PAUSED 界面，不重置结算和驾驶状态。

实际浏览器访问 `http://127.0.0.1:4176/`，刷新加载修复后：

1. 进入免费试驾并观察到 GAME OVER。
2. 点击车库：四车卡片显示正常，GAME OVER / RETRY 遮罩不再显示在车库上方。
3. 关闭车库后再次观察到原 GAME OVER、分数、RETRY 和车库按钮。

真实截图：`garage-overlay-fixed.jpg`。19 项现有自动测试通过；本轮命令行 HTTP 探测受 EACCES 限制，未作为失败的游戏功能处理。上述浏览器观察通过正常页面交互完成。
